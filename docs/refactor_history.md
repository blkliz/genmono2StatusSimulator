# リファクタ履歴

---

## 敵データ構造のリファクタ（2026.05.23）

### 背景

初期試作時は以下を優先して進めていた。

- HTML モック作成
- 少数テストデータ投入
- 表示確認・機能追加

また実装当時は JS 経験がほぼ無く、スプレッドシート側で文字列を連結してそのまま貼り付ける構造を採用していた。  
その後機能追加が進み、表示文字列構造がロジックへ浸透したことで、データ構造変更コストが高騰し負債化した。

---

### 旧構造

`lv`・敵名・カテゴリを単一の表示文字列として `name` に格納していた。

```js
{
  name: "Lv.135：盲鬼ト浮鬼 (常設(Grd9))",
  attr: "獣",
  abi: "強打",
  hp: 69000,
  atk: 7360,
  def: 3000
}
```

**問題点**

| 問題 | 詳細 |
|------|------|
| Lv 可変イベント敵への対応 | `split` 処理が必要になる |
| 敵名に `：` が含まれる場合 | 解析が破綻する |
| 密結合 | 表示文字列と内部識別子が分離されていない |
| 保守性・再利用性の低さ | データ単体での取り回しが困難 |

---

### 新構造

`lv` / `name` / `category` を分離した。

```js
{
  lv: 135,
  name: "盲鬼ト浮鬼",
  category: "(常設(Grd9))",
  attr: "獣",
  abi: "強打",
  hp: 69000,
  atk: 7360,
  def: 3000
}
```

**変更内容**

- `lv` / `name` / `category` を分離
- `split` 依存処理を削減
- Lv 可変イベント敵への対応を改善
- スプレッドシート生成関数を更新

---

> JS 初心者時代の試作優先実装による負債整理。

**スプレッドシート使用関数の変更**
変更前
```
{ name: 'Lv."&A2&"："&B2&" ("&C2&")', attr: '"&SUBSTITUTE(D2,".","")&"', abi: '"&E2&"', hp: "&IF(OR(F2="?", F2=""), 0, F2)&", atk: "&IF(OR(G2="?", G2=""), 0, G2)&", def: "&IF(OR(H2="?", H2=""), 0, H2)&" },"
```

変更後
```
{ lv: "&IF(A2="LVUP","'LVUP'",A2)&",name: '"&B2&"',category: '("&C2&")', attr: '"&SUBSTITUTE(D2,".","")&"', abi: '"&E2&"', hp: "&IF(OR(F2="?", F2=""), 0, F2)&", atk: "&IF(OR(G2="?", G2=""), 0, G2)&", def: "&IF(OR(H2="?", H2=""), 0, H2)&" },"
```
