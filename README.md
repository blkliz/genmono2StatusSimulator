### 開発・運用に関するお願い

本シミュレータは、個人による開発と、有志の皆様によるゲームデータの検証をもとに各有志の許可の範囲内で、私自身が内容を再検証しながら手作業で入力・整備することによって維持しています。

開発資源の分散を避け、継続的な保守とデータ整備を可能な限り維持するため、独立した派生版の乱立や、収録データを本プロジェクトとは無関係な用途に転用することは意図していません。

改修・保守の引き継ぎや、別環境での継続運用を検討される場合は事前に開発者へ相談し、可能な限り本プロジェクト内で協議・協力して進めていただけると幸いです。
なお、LICENCEに定める継承許諾の条件を満たす場合は、事前の開発者への相談は不要とします。

データの一括複製・抽出、スクレイピング、AI等を利用した加工を含む、収録データの独立した再利用についても、同様に事前の相談をお願いします。


### 継承・派生版について

開発者による本プロジェクトの更新が長期間停止し、通常利用されている複数の連絡手段を通じても相当期間にわたり応答が得られない場合は、LICENCEに定める条件に従い、有志による保守・運用の継承を認めます。

その後、開発者が復帰した場合には、可能な限り関係者間で協議し、開発・保守・データ整備を本プロジェクトの本流（本リポジトリを中心とする開発・運用）に集約することを希望します。

ただし、これは開発資源の分散を避けるための協力のお願いであり、後継版の即時停止や、本流への統合を義務付けるものではありません。

継承・派生版を運用する場合は、適用されるライセンス条件を遵守し、本流とは別の運用主体によるものであることが利用者に明確に伝わるよう配慮してください。
